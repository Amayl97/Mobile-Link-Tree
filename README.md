# 📱 Mobile Link Tree

A clean, modern, and mobile-first Link Tree designed to feel like a native smartphone interface. This project focuses on simplicity, responsiveness, and accessibility, making it easy for visitors to access all of your important links from a single page.

## ✨ Features

- 📱 Mobile-inspired UI
- 🎨 Clean and minimal design
- 📐 Fully responsive layout
- ✨ Smooth hover and transition effects
- 🔗 Easy-to-edit links
- ⚡ Built with pure HTML, CSS, and JavaScript

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

1. Clone the repository.

```bash
git clone https://github.com/yourusername/mobile-linktree.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No installation or dependencies are required.

## 🎨 Customization

You can easily customize the project by:

- Updating your profile picture
- Changing your name and bio
- Editing your social links
- Modifying the colors and fonts
- Adding or removing buttons
